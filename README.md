# Sobeit

It is a todo app BUT with a twist.

How to get the polymath beast satisfied with this app?
There are three screens in this app:

1. Goals
2. Habits
3. Todo

We first choose our goals.

Example
- I want to create an app launcher with Rust for linux.

Then we create habit(s) around it.

Example
- Learn Rust 20 min everyday
- Make 1 commit everyday

And for goals or habits, you might need to have some todo(s) or in general

Example
- Install ubuntu in VM to test other distro

Hence you create goals and habits + todo corresponding to goals.

Complete each habit everyday, and following the principle of mathematical induction, you will surely achieve your goal one day.
The green heatmap should give you that dopamine hit, you are now seeking in content consumption.
